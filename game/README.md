# game/ (not tracked)

Your own copy of the game goes here. Nothing in this folder is committed.

After `python tools/prepare_game.py <path to WET.iso>` it contains:

```
game/extracted/   files from the disc (default.xex, lu0, lu1, media, movies*, streams*, nxeart)
game/hdd/         created at runtime: save data / cache written by the game
```
